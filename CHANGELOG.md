# Changelog

All notable changes to the Signal & Noise theme are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

A pull request does not bump `Version` and does not tag — it closes an issue and
adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`, which stamps `style.css` **and** `readme.txt` together.

## [Unreleased]

- **The home page marks Home as the current page.** The header's current-page underline from 2026.10 skipped the front page, under an older reading of the owner's home-page rule. The owner has since said the home page takes design changes, only not new content, and asked for it. `inc/nav-current.php` now sets `aria-current="page"` on the Home link on the front page (a query string does not change it), so it gets the same blood underline as the current link on every other page. No other link on the front page is marked. `tests/nav-current.php` pins it (red against the old code: 2 failed), and `tests/tuned-channel-test-card.php` now fails if a stylesheet singles out the front page.
- **Page changes look like a channel change.** Moving between pages, the new page now appears top to bottom in eight hard 30ms steps, like a CRT refresh, instead of a crossfade. The old page is wiped away by the complementary clip in lockstep, so no band of the screen ever shows both pages. The wipe runs on the root snapshot, which is the size of the viewport, so each step is an eighth of a screen however long the page is and wherever it is scrolled. To get there, `main` no longer carries its `sn-main` transition name, which nothing used. A named `main` is snapshotted at full page height, so each step uncovered more than a screen. Header and footer keep their own names, so they stay put, and the per-note morph names still transition on their own. It sits inside `prefers-reduced-motion: no-preference`, and the existing reduce rule still turns view transitions off. Measured in Chrome 152 by pausing the two keyframes at 0, 30, 105, 165, 210 and 240ms: the old clip's top inset plus the new clip's bottom inset is 100% at every sample (12.5%/87.5%, then 37.5%/62.5%, and so on). The full cross-document run still needs a visible-window render.
- **Links into a page land on a red mark.** A search engine's text-fragment link (`#:~:text=`) now highlights the passage in the same blood-on-void pair as text selection, instead of the browser's yellow. `::target-text` has been Baseline since December 2024; other browsers keep their default. A heading reached by a `#fragment` gets a 2px blood rule in the margin at its left. It is a pseudo-element, so the heading text does not move, and it fades in once per arrival for readers who have not asked for less motion. In forced colors the rule stays visible in the text color. Measured in Chrome 152: the rule is 2px wide, 16.4px left of the heading, and the heading gains no padding. The contrast sweep measures the highlight in all three palettes.
- **The 404 test card no longer touches "SIGNAL LOST".** At 1440 the heading sat flush against the card's bottom edge (seen in a local WordPress 7.1.3 render). The card now keeps a `spacing-50` gap below it, on the doubled-class rule so core's constrained-layout margin reset cannot undo it. `tests/tuned-channel-test-card.php` pins the gap. Not yet checked in a live render.
- **The header shows which page you are on.** Since 2026.10 the header link for the current page carries `aria-current="page"` (`inc/nav-current.php`), but nothing showed it on screen. That link now keeps the nav's 2px blood underline drawn, the same rule the other links show on hover, so it reads as a tuned channel. The front page is never marked, so the home page is unchanged. The mobile overlay hides every underline, as before. In forced colors the underline takes the text color instead of disappearing. The rule is in both `critical.css` and `layout.css`, and `tests/critical-deferred-parity.php` declares it. Not yet checked in a live render.
- **The 404 is a test card.** Behind the decorative "404", the seven palette swatches run in order as calibration bars, with a PLUGE-style step row under them. Every bar is a palette token, so dark mode recalibrates the card. The digits switch from concrete to ink with a page-colored outline so they read over every bar. They are still `aria-hidden`, and "SIGNAL LOST" and its contrast are unchanged. On arrival the digits flicker once with the `glitchFlicker` keyframes, which `base.css` defined and nothing used. The flicker only runs when the reader has not asked for less motion. Forced colors drop the bars and leave the old 404. No template change. `tests/tuned-channel-test-card.php` covers both changes and goes red when a rule is removed or a bar uses a literal color. Not yet checked in a live render.
- **The reading progress on long notes is an FM tuning dial, and it runs without a script.** The 3px progress bar that `assets/js/article-toc.js` drew and re-measured on every scroll frame is gone. In its place is a 26px dial pinned under the header: 88 to 108 on a tick scale, with a blood needle and a faint tuned wash that sweep as the article is read. It reads 88 at the article's first line and 108 at its last, never counting the masthead or footer. The needle is a CSS scroll-driven animation on the article's view timeline (`animation-range: contain`), and the dial sits on the header's live bottom edge through anchor positioning, which keeps #322's reason without measuring anything. `inc/article-toc.php` prints the dial at the end of `<body>`, only when a note gets a TOC. It can't live inside the note: the note's `<main>` keeps a transform from its entry animation, which traps any fixed child. A browser without view timelines or anchor positioning, or a reader who asked for less motion, gets no dial rather than a frozen one. On dial pages only, `body` clips instead of hiding horizontal overflow. `overflow-x: hidden` made `body` a scroll container that never scrolls, the timeline bound to it, and the needle sat still (measured). TOC jumps land below the dial. The script keeps only the TOC's smooth scroll and focus. Forced colors keep the needle in a system color. Measured on WordPress 7.1.3: the dial is at the header's edge at 1440 and 375, the needle reads 0, 53 and 100 at the article's start, middle and end, and there is no dial under reduced motion. `tests/article-dial.php` covers it.
- **Four new reading aids for notes: timeline, key term, checklist and comparison table.** All four are in the editorial-conventions registry, marked unused, so `sn-site-facts{editorial_conventions}` hands out a pasteable exemplar for each. **Timeline** (`signal-noise/timeline`): a dated sequence on a vertical hairline with a blood marker per item and the date set above its sentence in small tracked capitals, so it never reads as the 01/02/03 steps panel. All core blocks, and each item opens with `<strong>Date.</strong>` like a steps item. Where the browser supports scroll-driven animation and the reader has not asked for less motion, each marker fills as its item scrolls into place, with no script involved. **Key term** (`signal-noise/term`): a dynamic block, `<dl class="sn-term">` with one `<dt>` and one `<dd>`. Both fields are plain text, escaped with `esc_html`, and edited through `PlainText`. It stays in the column at every width with a blood left rule, one size under the prose, so it cannot be mistaken for the sidenote's margin float. Each cell wraps its text in a `<p>` so the public verifier rebuilds the same paragraph break the ledger signs (`tests/blocks-render-parity.php` now covers it, and goes red without the `<p>`). **Checklist** (`is-style-checklist` on core/list, `signal-noise/checklist`): an empty box per item drawn as a CSS border. Nothing to tick and nothing stored, and the boxes print. **Comparison table** (`is-style-sn-table` on core/table): hairline rows, a small-caps header row, no zebra, a caption set like the steps label. A 30rem minimum width makes a phone scroll the table inside its figure while the page stays put (measured at 375px: page 375 wide, table 137px of in-figure scroll), and the caption stays pinned while it scrolls. Core's table editor never writes `scope` on header cells, so `inc/table-header-scope.php` adds `scope="col"` to this style's `<thead>` cells on render with the HTML API, and keeps any scope the author set. All four print cleanly (`assets/css/print.css`). Text and strokes are currentColor and the accent is the blood token in both palettes. Inserting each in the editor, saving and reloading left all 49 blocks valid with no recovery warning, on WordPress 7.1.3.
- **A printed note carries its own proof.** A new paper-only block, `signal-noise/print-colophon`, sits under the provenance panel in the note's closing part. It is hidden on screen. In print it writes out what a reader holding the page needs to check it: the version and the date it was recorded, the status as the panel presents it (a founding-snapshot note reads Verified once the snapshot is anchored), the Bitcoin block, the full SHA-256 of the signed text (the panel shows 12 characters), and the verify, ledger and note addresses as text, since on paper a link is only its text. The data is the companion plugin's public provenance record, read the way the chip and the panel read it. Without the plugin, or for a note with no chain, nothing renders. It sits inside the closing footer, outside the verifier's cut of the page, so it cannot touch the signed prose. Every value is escaped (`esc_html`, `esc_url`; a non-http address is dropped). It has its own sheet, so `print.css` is unchanged. `tests/print-colophon.php` covers it, and its escaping check goes red without `esc_html`.
- **The sidenote is margin-note size again on notes.** On a single note the prose rule `.sn-note-single .wp-block-post-content p` (0,2,1) also matched the sidenote's `<p>` and out-ranked its own rules (0,2,0), so the margin note rendered at prose size and line-height (14.4px measured at 1440, where its sheet asks for 12px). The two sidenote rules now double the class, `.wp-block-post-content .sn-sidenote.sn-sidenote` (0,3,0): the same elements, editor canvas included, winning whatever order the sheets load in. Measured after: 12px beside the column at 1440, 13.6px inline at 1024; prose unchanged. `tests/sidenote-note-size.php` resolves the cascade at both breakpoints (red before the fix: 4 failed).
- **The Spanish header nav writes its links through core's HTML API.** `sn_lang_nav_link_html()` (`inc/lang-chrome.php`) swapped the href with a regex on `href="..."` and added `aria-current` with another; it now uses `WP_HTML_Tag_Processor` (`next_tag`, `get_attribute`, `set_attribute`), so a `>` inside an earlier attribute value, a single-quoted or unquoted href, and `$1` or `\1` in the URL are parsed by core. Output for the rendered navigation-link is byte for byte the same; an odd source tag now comes out with a double-quoted href. `tests/lang-chrome.php` pins three such tags (red against the regex: 21 passed, 3 failed).

## [2026.10.10] - 2026-10-16 — emoji is back for readers

### Fixed
- **Emoji is back for readers.** 2026.10.9 removed WordPress's emoji loader from pages and oEmbed frames for CSP prep. The owner had already decided on 2026-09-29 that emoji stays on the public site, feeds and email, off in wp-admin only. The loader is restored, and a test now fails if the theme ever unhooks it. A strict CSP allows the loader's inline module by hash instead.
