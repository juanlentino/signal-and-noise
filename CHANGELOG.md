# Changelog

All notable changes to the Signal & Noise theme are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

A pull request does not bump `Version` and does not tag — it closes an issue and
adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`, which stamps `style.css` **and** `readme.txt` together.

## [Unreleased]

### Changed
- **Each /resume lane is its own page: the in-place switch is removed, and the other lane is prerendered.** The switch's two links go to `/resume/` and `/resume/?lane=operations`, each a full page from the server, so `assets/js/resume-switch.js` and its enqueue are removed (4,777 bytes, 1,952 gzipped). This replaces 2026.11.2's in-place switch and the fixes written for it that never shipped. With one address per lane, the server renders the lane on screen and its `aria-current`, the plugin writes that lane's title, canonical and `og:url`, and a screen reader hears the new page's title on arrival. A `#resume-operations` address now opens on music; nothing on the site or in its machine files links that way. `inc/speculation.php` adds one moderate prerender rule, `sn-resume-lanes`, printed on /resume and on its coded /r/CODE copies (the same page), for the switch's other link and the `.sn-resume-hunk` lane links the plugin's edition marks carry; it sits beside core's own rule, so core's query-string exclusion does not reach `?lane=operations`, and it is printed only when speculative loading is on. /cv gets no rule. The page change is the site's existing view transition (`assets/css/article.css`). llms.txt's résumé formats line adds "Markdown, operations" (`/resume.md?lane=operations`) when the plugin lists it. The head's "This page as JSON" alternate on /resume/?lane=operations is now `/resume.json?lane=operations`, matching the lane it returns (it was the bare `/resume.json`, the music lane); only operations is ever added, read as `sanitize_key` reads it. `inc/assets-frontend.php`, `inc/speculation.php`, `inc/llms-txt.php`, `inc/content-json.php`, `tests/lib/wp-html-api.php`, `tools/fetch-wp-test-core.sh` (core's speculation rules files, pinned to tag 7.1.2). ## [2026.11.2] - 2026-11-02 — The résumé's lane switch: Music and Operations & AI Strategy

### Added
- **/resume's lane switch: Music and Operations & AI Strategy.** Owner brief 2026-11-01 #2. The plugin stores both résumés in the page and hides the one not asked for at render time (`?lane=operations`); the theme draws and drives the switch. `assets/css/resume-switch.css`, English /resume only: the switch is drawn like the EN | ES switch (one hairline box split in two, the current lane filled, blood on hover and focus, 44px targets, underlined in forced colors), each lane's headline and subhead, the receipt marks (`verify`, `paper`, `code`), and "What I've Built" as publication cards. `.sn-resume-variant[hidden]` stays hidden over any group display rule. `assets/js/resume-switch.js`, deferred, English /resume only: a click shows the other lane in place, keeps `?lane=operations` (or the bare /resume/) in the address, and Back and Forward follow; a modified or middle click opens the link as a link, and every link works without the script. Each lane carries its own Download, so the download follows the lane with nothing rewritten.
- **The script reads `?lane=` exactly as the server does** (lowercased, stripped to `[a-z0-9_-]`, then operations or music), so `?lane=Operations` keeps the lane the page was rendered with; a switch changes only `lane` in the address, so a draft preview keeps its preview query (independent review of #2346).
- **llms.txt names both résumés' files.** The résumé formats line adds "JSON Resume, operations" and "PDF, operations" when the plugin lists them.
