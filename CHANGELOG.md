## [2026.10.13] - 2026-10-17 — house glyphs, section numerals and the finer details


- **Five more design details, built as the owner approved them from renders.** None changes a page's content or anything inside a signed region. **House glyphs:** every arrow (← → ↗ and the rest) and every numero sign on the site fell back to Courier New, because neither shipped font has them (measured with Chrome's platform-fonts report on /notes and a note). `tools/build-house-glyphs.py` now draws them in each face's own terms: arrows stroked at the face's minus-sign weight on its minus-sign axis, and № as "No." from that weight's own N, o and period. The result is four WOFF files of about 1 KB each, one per DM Mono weight and one for Bebas. `theme.json` declares each as an extra face of its family, limited by `unicodeRange`, so the browser takes only those code points from it, wherever they appear: theme templates, plugin output (the provenance chip's ↗), page content (a button's →) and CSS `content`. No markup changes, so the pillar cards keep `&#8470;` and the signed /notes and /provenance pages are byte-identical. Measured after: the arrows and № resolve to the new faces, and Courier New draws nothing. **Section numerals:** a note with three or more sections numbers them 01, 02 above each h2 in rust at eyebrow size, and its table of contents carries the same numbers. References is not numbered, and the generated text has empty alt text so a screen reader does not announce it. **Prose list markers:** a plain list in a note counts 01. and bullets with an en rule, its markers in rust; styled lists keep their own. No published note has a plain list today (58 checked), so this is for the next one. **Print running head:** printed notes and pages carry the title top left, the site top right and 01 / 05 bottom right, in mono at 8pt (Chrome prints page-margin boxes; other browsers print as before). Paragraphs no longer strand one line across a break. `inc/print-running-head.php` passes the title to the print sheet as a CSS string with every non-plain character hex-escaped, and its test goes red if escaping is removed. **Red caret:** the text cursor is blood in /notes search, the command palette and the contact form, and the contact message box grows with its text from today's five-line height. `tests/house-detail.php` pins all five, including reading each font's cmap with PHP. `tests/font-files.php` now covers `.woff` as well as `.woff2`.

- **Four design details from the site-wide research, built as the owner approved them from renders.** Each is CSS only, and none changes a page's content. **Hairline-true display type:** the note title and page h1/h2 display heads trim to cap height and baseline (`text-box: trim-both cap alphabetic`), so the letters sit on the rule above and below them instead of floating on Bebas's tall line box. The home hero title keeps its box, and browsers without `text-box` keep today's spacing exactly. **Noise floor:** the film grain settles to half strength over the first screen of scrolling, via a root scroll timeline. `filter: opacity()` scales whatever opacity a breakpoint sets, so the phone grain halves too. Measured in Chrome: `opacity(1)` at the top, `opacity(0.75)` half a screen down, `opacity(0.5)` past one screen, and no animation under reduced motion. **Crop-mark focus:** a keyboard-focused button also shows four blood corner ticks outside its outline, like print registration marks. They hang on the `.wp-block-button` wrapper because the link clips with `overflow: hidden`. The 2px outline is unchanged, and forced colors drop the ticks. **Signal lock:** a prose link's resting look is unchanged (color only, the settled design). On keyboard focus, and on hover where the pointer hovers, its underline tunes in from an 8px offset to the house 3px and thickens to 2px in three hard steps. Rust paragraphs, sidenotes and footnote markers keep their own rules. `tests/signal-detail.php` pins all four (red before: 12 failed), and the existing `dark-mode` and `sidenote-scope` guards held it to their rules during the build.
