## Task 1 — Related Notes footer (M)
**Files:** Create `inc/related-notes.php` (~120 LOC) + `tests/related-notes.php`. Modify `functions.php` (require), `templates/single.html` (inject block), `assets/css/components.css` (styles).
**Change:**
- `sn_related_notes_query( $post_id, $limit = 3 ): array` — pure helper. Collect the note's `post_tag` term_ids; PRIMARY: `WP_Query(['post_type'=>'post','post_status'=>'publish','post__not_in'=>[$id],'posts_per_page'=>$limit,'orderby'=>'date','order'=>'DESC','tax_query'=>[['taxonomy'=>'post_tag','field'=>'term_id','terms'=>$tag_ids]],'no_found_rows'=>true,'ignore_sticky_posts'=>true])`; BACKFILL to `$limit` with most-recent published posts excluding self + already-selected. Returns WP_Post[].
- `sn_related_notes_shortcode(): string` — for `get_the_queried_object_id()`; return '' if 0 results. Render `<footer class="sn-related-notes">` + h2 "More on this" (brand mono/tracked label) + `<ul class="sn-related-notes__list">` reusing the `.sn-notes-row` two-column idiom (mono date + reading-time spec column via the `function_exists('sn_get_reading_time')` guard; Bebas-Neue linked title). Title-only (no excerpt, no matched-tag label). Escape everything (`esc_url`/`esc_html`).
- `add_shortcode('sn_related_notes', ...)` + a `render_block` bridge: `if ( false !== strpos( $content, '[sn_related_notes' ) ) $content = do_shortcode( $content );` (mirror `inc/setup.php:62-67`).
- `templates/single.html`: insert `<!-- wp:shortcode -->[sn_related_notes]<!-- /wp:shortcode -->` in the footer region — placement: after `post-closing` (prev/next), before the pillar/back links (single.html ~28-41).
- `functions.php`: `require_once` `inc/related-notes.php`.
**Test (`tests/related-notes.php`):** stub `WP_Query`/`get_the_terms`/post fixtures. Assert: shared-tag matches returned (recency DESC, self excluded); backfill tops up to N when shared-tag < N; 0 fixtures → shortcode returns ''; the render bridge runs do_shortcode when the token is present.
**Commit:** `feat(notes): Related Notes footer (shared-tag heuristic, render_block bridge)`
